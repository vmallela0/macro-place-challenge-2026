# `vmallela` — shared infrastructure (legacy)

This directory contains the original `vmallela` submission code (incremental
coordinate descent with parallel restarts, mean **1.4156** on 17 IBM
benchmarks). It is no longer the active submission, but the v7 placer
imports shared utilities from here at runtime.

**The current submission is `submissions/vmallela_v7/`.**
See [`../vmallela_v7/README.md`](../vmallela_v7/README.md) for the algorithm,
math derivation, and grader-verified results.
